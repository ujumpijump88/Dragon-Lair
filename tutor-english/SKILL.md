# 初三英语辅导（人教版九年级）

## 核心语法体系（中考高频）

1. **时态**：一般现在/过去/将来、现在完成时（have/has + 过去分词）、过去进行时、现在进行时
2. **被动语态**：be + 过去分词；一般现在被动/一般过去被动/含情态动词被动（can be done）
3. **定语从句**：that/which/who/whose/where/when；先行词判断
4. **宾语从句**：语序用陈述语序；时态呼应（主过从过）
5. **状语从句**：if/unless/because/so that/although；主将从现
6. **情态动词**：can/could/may/must/have to/should；推测用法（must be/can't be/may be）
7. **非谓语**：动词不定式（want to do）、动名词（enjoy doing）

## 教材重点话题（Unit 1-14）

学习方法、节日文化、问路指路、过去习惯（used to）、产品制造（被动）、发明历史、规则许可（be allowed to）、推测（belong to/must be）、音乐喜好（定语从句）、习俗礼仪（be supposed to）、情感影响（make sb do）、意外经历（过去完成时）、环保（现在进行时表趋势）、毕业回忆（remember doing）

## 完形/阅读技巧

- 完形填空：先通读全文抓大意 → 再逐空分析（词义辨析/语法线索/上下文呼应）
- 阅读理解：题干关键词定位原文；主旨题看首尾段；推断题找暗示
- 七选五：看空前空后衔接词（but/so/however）

## 作文模板框架

- 开头：引出话题（Nowadays, ... / As we all know, ...）
- 中间：分 2-3 点（First of all, ... Besides, ... What's more, ...）
- 结尾：总结+呼吁（In a word, ... / Let's ... together）
- 高分句型：定语从句、宾语从句、It's + adj + for sb to do

## 易错点（判改时重点检查）

1. **时态混用**（主句过去时从句却用现在时）
2. 被动语态**漏 be 动词**（done 直接作谓语）
3. 宾语从句**语序错误**（用疑问语序）
4. 定语从句**关系词选择错误**（人 who/物 which/时间 when）
5. **主将从现**（if 从句用将来时）
6. 名词单复数/动词三单/不规则动词过去式

## 讲题要点

- 语法题：先问"这个空在句中做什么成分？前后时态线索是什么？"
- 完形：先问"这段大意是什么？这个词和上文哪个词呼应？"
- 作文：先给框架，让学生填内容，不代写
- 判改：标注错因类别（语法/拼写/搭配），不给整句改写，引导自己改
