# 初三物理辅导（人教版九年级）

## 考点地图（按教材章节）

1. **内能**：分子热运动、内能、比热容 Q=cmΔt、热机、热值
2. **电流和电路**：电荷、电流方向、串联并联、电流表使用
3. **电压 电阻**：电压表、串并联电压规律、电阻影响因素、滑动变阻器
4. **欧姆定律**：I=U/R；串并联电阻规律；伏安法测电阻
5. **电功率**：P=UI；额定功率 vs 实际功率；焦耳定律 Q=I²Rt；电能表
6. **生活用电**：家庭电路、保险丝、安全用电
7. **电与磁**：磁场、电生磁（奥斯特）、磁生电（法拉第）、电动机发电机
8. **能源**：能量转化与守恒

## 核心公式速查

- 比热容：Q = cmΔt（吸热放热）
- 欧姆定律：I = U/R；串联 R总=R₁+R₂；并联 1/R总=1/R₁+1/R₂
- 电功率：P = UI = U²/R = I²R；W = Pt = UIt
- 焦耳定律：Q = I²Rt（纯电阻电路 Q=W）
- 串联：电流处处相等，电压按电阻分配
- 并联：电压相等，电流按电阻反比分配

## 易错点（判改时重点检查）

1. **串并联判断错误**（电流有几条路径）
2. 欧姆定律**单位换算**（mA/A, kΩ/Ω）
3. 电功率**额定 vs 实际**混淆（灯泡亮度看实际功率）
4. 焦耳定律**适用条件**（非纯电阻电路不能用 Q=U²/R·t）
5. 电压表电流表**量程/正负接线柱**接错
6. 家庭电路**开关接火线**、保险丝接火线

## 讲题要点

- 电学计算：先问"这是个串联还是并联电路？各表测谁？"→ 画等效电路图
- 力学（浮力/压强若涉及）：先问"物体处于什么状态？受力分析做了吗？"
- 热学：先问"哪个物体吸热哪个放热？Δt 怎么求？"
- 判改：重点看"是否先判断电路结构再代公式"
